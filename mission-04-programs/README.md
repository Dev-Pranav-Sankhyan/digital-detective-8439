### Task 4.2 - Compare compiler and interpreter

| Point | Compiler | Interpreter |
| :--- | :--- | :--- |
| When translation / execution happens | Translates the whole code before running | Translates and runs line-by-line on the fly |
| Typical output | A machine code file (like .exe) | No extra file, just the result of the program |
| One example | C++ | Python |
| One advantage | Runs much faster once compiled | Easier to test and debug quickly |

**Explanation:**
A compiler takes your entire code and translates it into machine code upfront before it even runs. An interpreter reads and executes the code line-by-line while the program is running. Basically, compilers are better for fast final programs, while interpreters are easier to test with as you code.
