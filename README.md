## How to run the Number Converter[cite: 11]
To use the Python number converter built in Mission 5:
1. Open your terminal.
2. Navigate to the folder: `cd mission-05-numbers-data`
3. Run the script: `python3 number_converter.py`
4. Enter a decimal number when prompted to see its binary and hexadecimal values.
